    Help

    This dashboard shows what N.I.N.A. is doing on one or more observatory PCs. It is read-only: nothing here can control NINA.

    Getting around

    • View (top left): My dashboard is your own mix of cards from any NINA; Full view shows every card for one NINA.
    • Device chips: one per NINA. The dot is green when all is well, amber when unsafe or there are errors, red when offline; ▶ means a sequence is running. Click a chip to open its Full view.
    • Tabs in the Full view: Overview, and Target Scheduler when that plugin is in use.
    • Cards: the chevron (or the title) collapses a card; the camera button saves a snapshot. Hover a card title to see what it shows.
    • Devices adds NINAs; Config picks which cards each NINA shows and exports or imports your setup. Edit layout rearranges My dashboard.
    • Observatory time / My time picks the time zone for all times; Compact and Night change the display.

    Getting help

    • Read the documentation (setup, Tailscale, API key, hosted dashboard).
    • Report a problem or request a feature on GitHub. Include the NINA and plugin versions and any messages from the Errors & warnings card.
    • Ask on the Naztronomy Discord.
    • A card that says offline can't reach that NINA: check the PC is on, NINA is running with the plugin enabled, and the address and API key in Devices.
